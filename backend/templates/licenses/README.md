Templates adapted from Jake Gutierrez's resume (MIT), https://github.com/jakegut/resume,
and Debarghya Das' Deedy Resume OpenFonts edition (Apache-2.0), https://github.com/deedy/Deedy-Resume.
Deedy font files are included under their SIL Open Font Licenses (Lato and Raleway).
Layout adaptations insert validated user data, preserve optional sections, and escape TeX input.
