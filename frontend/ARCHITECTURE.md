# MatchMyRole frontend

React and TypeScript with Vite. Feature screens live in `src/features`; shared controls and the application shell live in `src/components`.

ResumeContext owns editable resume data, analysis results, optional device autosave, and saved application versions. InteractionContext coordinates dialogs and drawers. API requests use the shared services layer.

The application shell provides one background image for every route. Shared surfaces, inputs, buttons, and navigation colors are defined in `src/index.css`; dock selection and primary buttons reuse the same accent tokens. Workspace pages share responsive spacing. The builder stacks below 1200px and keeps its PDF preview beside the editor on larger screens.

PDF rendering is loaded separately from the initial screen. Exports are generated by the backend; the preview displays the exported PDF rather than a separate approximation.

Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build` before shipping. Workflow tests cover input validation, editing, suggestions, versions, export, and shared route layout.

The editor, skills, and cover-letter routes load on demand behind a Suspense boundary inside the shared shell. Vite handles shared chunks automatically; PDF.js remains a separate download. Snapshot serialization is memoized and reused by autosave and version comparisons. API services share one resume FormData builder to keep input selection and seniority consistent.

Tooling: Vite 8, Vitest 5, React Router 7, Node 24 in CI. The build explicitly retains the previous browser targets (including Safari 16). Unused query/theme/typography dependencies have been removed.
